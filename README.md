Автоматический респавн игроков на волне по таймеру с гибкой настройкой логики активации.

## 📝 Описание

Мутатор для автоматического возрождения игроков на волне по истечении заданного времени. Основная особенность — возможность настройки процентного соотношения живых и мёртвых игроков для активации и деактивации таймера респавна.

## 👨‍💻 Авторство

- **Оригинальный автор:** Dave_Scream
- **Доработки и исправления:** RaideN-

## 🔧 Исправления и улучшения

- **Исправлен** учёт пешек (Pawn) — боты (например, SentryBot) теперь **не учитываются** при подсчёте живых и мёртвых игроков
- Система активации/деактивации таймера работает корректно только с реальными игроками

## ⚙️ Основные возможности

- Автоматический респавн по таймеру на волне
- Настройка времени до возрождения
- Конфигурируемое процентное соотношение живых/мёртвых игроков для:
  - Запуска таймера респавна
  - Остановки таймера респавна
- Игнорирование ботов в подсчётах

## ⚠️ Важно

Данный мутатор является **исправленной версией** оригинального мутатора Dave_Scream. Все изменения направлены на улучшение стабильности и корректности работы логики респавна.
